# Голосовые команды и проверка

Долгое нажатие кнопки ассистента вызывает панель с коротким звуковым сигналом. Сам диалог идёт из приложения на колонке через OpenAI API. Подготовленный ключ Groq отдельно включает диктовку Android. Доступность интернет-сервисов зависит от сети и разрешений. Будильник хранится и звучит локально, голосовая команда для него требует доступного ассистента.

| Пример | Что делает | Что подтверждено |
| --- | --- | --- |
| «Который час?», «Объясни, почему …» | Диалог и базовые вопросы | Ответы слышны с колонки |
| «Запомни, как меня зовут», «Запомни город для погоды», «Говори о себе в женском роде» | Сохраняет профиль на устройстве для новых разговоров | Все три поля правильно прочитаны после повторного вызова плавающей панели |
| «Запомни, что …» | Сохраняет явно добавленную заметку | Реализовано, отдельная проверка заметки после нового сеанса ещё нужна |
| «Какая погода?» | Использует сохранённый город, если другой не указан | Город сохраняется, прогноз с ним как отдельный сценарий ещё не проверен |
| «Поставь будильник через минуту», «Поставь будильник на 07:30» | Планирует локальный будильник | Минутный будильник зазвонил, время и фокус полей проверены на ТВ |
| «Выключи будильник» | Останавливает текущий звонок | Сработало голосом |
| «Открой Spotify», «Открой альбом Meteora в Spotify» | Запускает приложение или открывает найденный альбом | На телевизоре открылся нужный альбом |
| «Включи любимые треки в Spotify» | Открывает личную коллекцию и запускает трек | Проверено пользователем при выключенном телевизоре |
| «Открой мой плейлист …» | Использует заранее сохранённую ссылку с именем | Ссылку можно сохранить. Запуск личного плейлиста пока отдельно не проверяли |
| «Выключи музыку», «Пауза» | Ставит активную медиасессию на паузу | Spotify остановился |
| «Следующий трек», «Предыдущий трек» | Передаёт команду активному плееру | Оба направления проверены на устройстве, следующий трек подтверждён пользователем |
| «Громкость 7», «Громче», «Тише» | Значение на шкале 0–10 или относительный шаг | Команда установки уровня проверена. Пример: 7 означает примерно 70% диапазона Android |
| «Найди … на YouTube», «Открой это видео» | Передаёт запрос или известный идентификатор в TizenTube | Переход на видео и выдачу проверен. Встроенный микрофон поиска TizenTube работает отдельным путём и остаётся вне этой проверки |
| «Открой Twitch» | Запускает Twitch | Проверено. Прямой запуск стрима по имени в текущем клиенте не работает. Диктовка через микрофон LeanKeyKeyboard вставляет текст в поиск Twitch |
| «Найди Интерстеллар в Лампе» | Открывает карточку фильма или сериала в Lampa через данные каталога | Прямые ссылки на карточки проверены, полная цепочка голосом и запуск воспроизведения ещё не подтверждены |
| «Открой VLC» | Открывает установленный VLC | Команда поддерживается, отдельная проверка запуска из разговора не зафиксирована |

## Личный плейлист

Скопируйте ссылку на нужный плейлист из Spotify. Сохраните короткое узнаваемое имя. Используйте собственный профиль и клиент со входом.

```sh
adb shell 'content call --uri content://org.yanalice.voice.setup --method save-spotify-playlist --arg '\''{"name":"В дороге","link":"https://open.spotify.com/playlist/REPLACE_WITH_PLAYLIST_ID"}'\'''
```

## Микрофон пульта

В тесте колонка распознала живую фразу и со встроенного микрофона, и по BLE с пульта. В длительном разговоре BLE-вход один раз потерял связь и открылся повторно в том же сеансе. В приложениях поиск зависит от того, вызывают ли они системный распознаватель или свой ввод. Для Twitch проверен микрофон клавиатуры.

## Кнопки и индикация

Четыре нажатия Mute на корпусе проверены с рабочим аппаратным профилем. Повторная попытка полностью заменить IoSDK сохраняла Bluetooth-звук, но теряла индикацию до подключения и управление громкостью. Итоговый профиль сохраняет штатный компонент под сетевым запретом. Отдельный эксперимент с двойным коротким нажатием кнопки ассистента переключал Bluetooth. Нужно ещё проверить, что после отключения питания работают оба жеста на пульте: двойное нажатие для Bluetooth и удержание для вызова ассистента.
