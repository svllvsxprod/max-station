# Передать настройку агенту

Передайте агенту ссылку на этот репозиторий и текст ниже. Укажите модель, версию прошивки и что сейчас происходит при включении. Серийные номера, ключи, логины и конфигурации сети держите локально.

> Подготовь мою колонку Max как локальный Bluetooth-приёмник и Android TV. Сначала проверь модель, версию Android и сборку, какой экран открывается и есть ли ADB. На этом этапе ничего не меняй. Используй руководство docs/setup.md и остановись на первом несовпадении оборудования, прошивки или прав. Укажи, какой шаг требует моего участия. Все первичные проверки выполняй в сети без WAN.
>
> Сначала помоги проверить кабель и получить авторизованный ADB. Для начальной прошивки используй AliceBridge только по инструкции его авторов для нашей ревизии. Не выполняй записи в boot/system/AVB, не меняй серийный номер, не ставь донорскую прошивку. Перед удалением пакетов сохрани инвентаризацию и установи новый Home, клавиатуру и ярлыки. Удаляй пакеты небольшими группами по docs/packages.md. После каждой группы проверь точный состав, настройки, пульт и звук. Шесть оставленных пакетов сохрани.
>
> Закрой доступ в интернет по умолчанию и проверь маршрутизацию, в том числе остановку фильтра, IPv6 и системные UID. Для выхода через VPN используй туннель на роутере. Не объявляй раннюю изоляцию доказанной по результатам теста после загрузки. Применяй только сетевой профиль, подтверждённый для моего устройства.
>
> Скачай оригинальные APK проекта из релиза, сверь хеши и установи. Открывай локальную форму ключа для моего ручного ввода. Подготовь помощника, выбранные приложения и мой Spotify. Проверь документы docs/commands.md и звук при выключенном ТВ. Не заменяй реальный тест по HDMI, Bluetooth или звуку ответом API. Верни короткий список выполненного, ручных шагов и вещей, которые ещё не проверены.

## Что возвращать после каждого этапа

| Этап | Что должно остаться в отчёте |
| --- | --- |
| Идентификация | Модель, Android, версия, вид экрана, статус USB/ADB без серийного номера |
| Настройка | Каким способом подготовлено устройство, финальная версия, права обычной и временной сессии |
| Очистка | Списки user 0 до и после, отдельно активный Device Owner, результат пробы Home/пульта/Bluetooth |
| Сеть | Разрешённый и запрещённый сценарии, отказ при остановке VPN, интерфейсы и IPv4/IPv6, отдельно окно до старта Android |
| Приложения | Источник и версия, статус входа, сценарий воспроизведения |
| Голос | Реальная фраза с пульта, повторный вызов, память, будильник, пауза, «Любимые треки» с выключенным телевизором |

Физические действия владельца обычно включают кабель, подтверждение ADB и разрешений, первичную настройку на телефоне, ввод API-ключей и проверку реального звука. Стадии независимы. Если доступна только часть, зафиксируйте рабочее состояние и условие продолжения.
